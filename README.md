# 🍽️ ระบบสั่งอาหารผ่าน QR Code

ระบบสั่งอาหารสำหรับร้านอาหารขนาดเล็ก พัฒนาด้วย HTML/CSS/JavaScript ใช้ localStorage เก็บข้อมูล

## 📁 โครงสร้างไฟล์

```
food-order-qr/
├── login.html      # หน้าเข้าสู่ระบบ
├── register.html   # หน้าสมัครสมาชิก
├── customer.html   # หน้าสั่งอาหาร (ลูกค้า)
├── staff.html      # หน้าครัว (พนักงาน)
├── admin.html      # หน้าจัดการ (แอดมิน)
├── style.css       # ไฟล์ CSS รวม
├── app.js          # ไฟล์ JavaScript รวม
└── images/         # โฟลเดอร์รูปภาพ
```

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: เปิดตรงๆ ในเบราว์เซอร์
1. ดับเบิลคลิกไฟล์ `login.html` หรือ `customer.html`
2. ระบบจะทำงานได้ทันที

### วิธีที่ 2: ใช้ Live Server (VS Code)
1. ติดตั้งส่วนขยาย "Live Server"
2. คลิกขวาที่ `login.html` → "Open with Live Server"

### วิธีที่ 3: ใช้ Python HTTP Server
```bash
cd food-order-qr
python -m http.server 8000
```
แล้วเปิดเบราว์เซอร์ที่ `http://localhost:8000`

| แอดมิน | admin | admin123 |

## 📱 หน้าสำหรับลูกค้า (QR Code)

URL สำหรับสร้าง QR Code:
```
customer.html?table=1  # โต๊ะ 1
customer.html?table=2  # โต๊ะ 2
customer.html?table=3  # โต๊ะ 3
```

## 🎨 ฟีเจอร์หลัก

### ระบบลูกค้า
- 📋 ดูเมนูอาหารพร้อมราคา
- 🛒 เพิ่ม/ลดจำนวนในตะกร้า
- 📝 เพิ่มหมายเหตุถึงครัว
- 💬 แชทสดกับครัว
- 🛎️ เรียกพนักงาน
- 📊 ติดตามสถานะออเดอร์

### ระบบครัว
- 📥 รับออเดอร์แบบเรียลไทม์
- 🔄 เปลี่ยนสถานะอาหาร
- 💬 ตอบกลับข้อความลูกค้า
- 🔔 แจ้งเตือนออเดอร์ใหม่

### ระบบแอดมิน
- 📊 ดูยอดขาย/สถิติ
- 🍽️ จัดการเมนู (เพิ่ม/แก้ไข/ลบ)
- 📋 ดูออเดอร์ทั้งหมด
- 💰 บันทึกการชำระเงิน
- ⚠️ จัดการปัญหาที่แจ้ง

## 🗄️ ข้อมูลที่เก็บใน localStorage

- `food_order_users` - ข้อมูลผู้ใช้
- `food_order_menus` - เมนูอาหาร
- `food_order_orders` - รายการออเดอร์
- `food_order_cart` - ตะกร้าสินค้า
- `food_order_messages` - ข้อความแชท
- `food_order_notifications` - การแจ้งเตือน
- `food_order_issues` - รายงานปัญหา
- `food_order_current_user` - ผู้ใช้ปัจจุบัน

## 🎨 สีที่ใช้

- **พื้นหลัง**: ขาว / เทาอ่อน (#F5F5F5)
- **สีหลัก**: เขียว (#2E7D32)
- **สีรอง**: น้ำตาล (#8D6E63)
- **สีเน้น**: ส้มอ่อน (#FF8A65)
- **ปุ่มหลัก**: เขียวเข้ม / ส้ม

## 📝 หมายเหตุ

- ข้อมูลจะหายเมื่อล้างข้อมูลเบราว์เซอร์
- รองรับการใช้งานบนมือถือ (Responsive)
- ไม่ต้องติดตั้งฐานข้อมูลหรือเซิร์ฟเวอร์
